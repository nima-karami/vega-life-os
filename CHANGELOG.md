# Changelog

The release history is the [GitHub Releases](https://github.com/nima-karami/vega-life-os/releases):
one CalVer `vYYYY.M.N` tag per deploy, with the notes and a Deploy block
([ADR 0005](docs/adr/2026-10-22-0005-calendar-versioning.md)).

`npm run changelog` renders the full history into this file on demand. It is not committed
after each release.
